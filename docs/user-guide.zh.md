# TurboSync 使用指南

TurboSync 的日常入口是终端同步控制台：

```bash
tsync dashboard
```

它默认显示中文，按 `l` 可以切换到 English。通常只需要运行这一条命令。

## 第一次使用

直接打开控制台：

```bash
tsync dashboard
```

第一次运行时，TurboSync 会自动初始化本机状态，并启动本地后台同步服务。这个服务如果是由 `dashboard` 自动启动的，退出控制台时会自动关闭；如果服务本来已经在运行，`dashboard` 不会关闭它。

Agent 指的是这个本地后台同步服务。它负责扫描文件、监听变化、执行同步。普通使用不需要手动运行 `tsync agent run`；这个命令主要用于开发、调试或想在前台查看日志时使用。

## 在仪表盘里操作

常用按键：

| 按键 | 作用 |
|------|------|
| `j` / `k` | 上下选择任务或文件 |
| `s` | 同步选中的任务 |
| `w` | 开启选中任务的文件监听 |
| `x` | 停止选中任务的文件监听 |
| `e` | 编辑选中的任务 |
| `f` | 查看文件索引，再按一次返回任务列表 |
| `r` | 刷新状态 |
| `l` | 在中文和 English 之间切换 |
| `?` | 查看帮助 |
| `Esc` / `q` | 返回或退出 |

同步控制台会突出显示：

- 后台同步服务是否在线
- 同步任务列表
- 选中任务的“源目录 → 目标目录”链路
- 同步策略、监听状态和快捷操作
- 最近同步活动
- 同步进度
- 文件索引和同步状态

## 添加同步目标

如果要同步到另一台设备，先在另一台设备上运行 Agent，然后在本机添加节点：

```bash
tsync node add nas 192.168.1.20:38746
```

添加任务：

```bash
tsync task add documents \
  --source ~/Documents \
  --target-node <node-id> \
  --target-path /backup/Documents
```

之后回到仪表盘：

```bash
tsync dashboard
```

选择任务后按 `s` 手动同步，按 `w` 开启自动监听。

## 查看结果

在仪表盘里：

- 右侧“当前同步链路”会显示同步方向、源目录、目标目录。
- 最近活动会显示同步是否成功。
- 按 `f` 可以查看已索引文件、hash、大小和同步状态。

命令行也可以查看：

```bash
tsync status
tsync task list
tsync logs --limit 20
```

## 注意事项

- Agent 需要保持运行，TUI 才能连接和操作。
- 第一阶段主要面向个人设备、NAS 和 Homelab 场景。
- 删除同步会把源目录中的删除同步到目标目录。
- 远端同步建议在可信网络中使用，并配置远端证书指纹。
